# HDDに配置して運用する流れ

## 配置

```text
AI_VAULT/
  portfolio/     GitHubから取得するこのリポジトリ
  store/         モデル・データ・実行資材・知識資料の実体
  state/         実機の進捗、照合結果、実行結果、非公開の承認証跡
  cache/         ダウンロードクライアントの一時キャッシュ
  staging/       取得途中・検査待ちのデータ
```

この図のHDD上のフォルダーはまだ作成していない。D:などの文字は固定しない。
config/local.example.jsonをconfig/local.jsonにコピーし、実機で確認したvault_rootと識別情報を設定する。コピーはローカル作業であり、この整理では実行していない。
store等の相対名はvault_rootに対して解決し、portfolioの外側かつ対象HDD内にあることを検査する。
トークンはリポジトリやlocal.jsonに保存せず、ユーザーが管理する認証手段を使う。キャッシュ先の変更で認証ファイルまで共有HDDに移さない。

## 1. 選ぶ

catalogに1件登録する。欲しい用途・原本/派生の比較目的・消失への備えを記録する。
選定は将来の規制の確証を待つ必要はない。ただし、取得元・権利・容量の未確認を免除しない。

## 2. 取得内容を固定する

配布元を読み、完全なコミット、全シャードと付属物、明示したファイル名、バイト数、利用条件を確定する。
元の設定、tokenizer、processor、必要な画像・音声encoder、codec、量子化補助物を取りこぼさない。
ランタイムはモデルと別資産として、ソースの版、動作済みバイナリ、OS/CPU/GPU、ドライバー、Python ABI、必要wheel等を対応づける。
コードを保存することと、それを実行することを分ける。外部APIやオンライン認証が必要なら完全オフライン対応としない。

## 3. 承認する

選択ファイルと依存を含むマニフェスト、必要容量、未解決事項を提示する。ユーザーがその固定内容を承認したらキューに入れる。
まとめて承認された範囲では1件ごとの再承認は不要。未承認の追加、利用条件への同意、実行やインストールは別許可。
現在はキューが空なので、ここで停止する。

## 4. 実機で取得する（実行機能は今後実装）

対象HDDを照合し、保存予算と実空き容量、cache/stagingのピーク使用量を確認する。
保存目標3.8TBと空き200GBの両方を守る。HDD上の既存テストファイルも空き容量を消費する。
既定は1資産ずつ。並列数を増やす場合も総作業領域を先に見積もる。
固定版と列挙ファイルだけを取得し、中断時の再開情報をstateへ記録する。既存完成ファイルは照合し、正常なものを再取得しない。
通信・権限エラーは原因を記録。容量不足や保存先不一致なら全体を停止する。

## 5. 検証・記録する

| 軸 | 記録例 |
| --- | --- |
| 選定 | candidate / selected / held / excluded |
| 取得 | not_started / downloading / downloaded / blocked / failed |
| 整合性 | unchecked / matched_upstream / local_hash_recorded / mismatch |
| 実行 | not_tested / offline_pass / failed |

stateの取得記録には、マニフェストSHA-256、時刻、ファイルパス、実サイズ、ローカルSHA-256、配布元照合結果、クライアント版を残す。
offline_passにはOS、backend、ライブラリ版、使用機器、入力例と出力、ネット遮断条件を添える。1用途の成功を全用途対応に拡張しない。
学習用と評価用のデータ、原本と変更版は識別を維持する。

## 6. 推論・学習は別工程

取得キューはモデルを実行しない。試験する際は別に許可を得て、秘密情報・ホストの重要ファイル・外部ネットワークへの権限を制限する。
モデル・実装・依存の3点が揃い、ネット遮断下の試験を通って初めて、試験した範囲で再実行可能と記録する。

## 次の実装単位

まず1件のメタデータ固定と容量集計、次に承認済み1件の取得・中断再開・照合を作る。大規模な自律選定や全件ダウンロードを先に作らない。
必要な試験は、空キューでは書き込まないこと、未固定版/未知容量を拒否すること、HDD不一致/容量不足で停止すること、ハッシュ不一致で成功扱いしないこと、取得コードがモデルを実行しないこと。
