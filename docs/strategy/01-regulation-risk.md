## 3. 旧分類の問題と新たな優先順位の理由

旧S1→S2→S3はストレステストには有効だが、時間順序の実証がない。保全価値の最上位評価として使用すると、(i) 現在Gatedでも代替不能なS3 DINOv3エンコーダ、(ii) 非再現的な多言語注釈、(iii) 軽量で異なる構造を代表するSSM/拡散LLM/時系列モデル、(iv) 音声復号Codecなどの依存が後回しになる。一方S1には同系統の蒸留・派生重みが多数あり、重複を測らず一律最優先にする根拠はない。

新しい二軸判断：**①非交渉の法令・パラメータ数・ライセンス・明示承認ゲート**と、**②非実行の調査優先度（正規アクセス摩擦、代替困難な学習成果、独立タスク、依存・研究再現性、検証可能な保存コスト）**を分離する。

| 調査帯 | 調査の目的 | 実行ゲートへの影響 |
| --- | --- | --- |
| P0 | Gated、同意・権利衝突、データ削除要請、不可欠な依存や独自原本の一次調査 | **取得権限なし。** HOLDは継続HOLD、Gatedの正規承認が必要 |
| P1 | 単独の高度能力ではなく、再現困難な専門データ・元重み・小型多様性・研究再現性を優先 | 旧S3もここに昇格可。取得承認ではない |
| P2 | ベースライン、代替性・重量・独立性能の比較、総数未確認の静的監査 | **総数不明のモデルは準備停止** |
| P3 | 追加価値が弱い重複/旧世代、予算不足、権利/利用選定の未解決 | 監視継続、選定・取得の格上げ不可 |
| PX | 全パラメータ数が150B以上確定 | **絶対除外。** MoE活性値・量子化・SSD offloadは例外不可 |

実務例：`facebook/dinov3-vith16plus-pretrain-lvd1689m` は旧S3にもかかわらず `speridlabs/idol` の依存としてP0で権利審査を行う。`lightonai/LightOnOCR-3-0.8B`、`autogluon/chronos-2`、`RWKV/RWKV7-7.2B-20260805` は旧S3の低い規制シナリオ露出とは独立に、専門能力・構造の保存価値でP1へ移した。一方9.23TBの `nvidia/PhysicalAI-Autonomous-Vehicles-Foundation4D` は現行保存予算を超過し、権利が確認できても一括原本保存は不適格。許可されたsplit調査以上に進めない。

## 4. 150B・資産の権利・物理資源：ハード停止条件

1. **パラメータ数の判定**：全パラメータ（MoEの全expert、embeddingやMTPなど独立学習部品を含む）が**150,000,000,000以上なら除外**。既知の対象は `orcarouter/Qwen3.8-Flash-Next-Uncensored` 約180B、`mistralai/Mistral-Large-4-1T-A52B` 約1.05T。未知12件は、チェックポイントを実行せず静的構造調査で総数が確定するまで**取得準備を停止**。v9の95件PASSは公表概数を含み、すべての依存モデルの総数・実機条件を証明しない。
2. **権利が優先する**：公開元の一次URLとライセンス正文、変更日、Gated同意、利用者別許可、医療・音声・人物・コード原著作権、削除請求を検証する。安全保障や悪用リスクを無断取得の正当化に使わない。
3. **原本同一性**：取得前に固定commit（40字SHA等）、全シャード・構成、必要な依存と各ファイルのサイズ、SHA-256、同一原本の正規代替元を確認する。自動実行・pickleロード・未審査コードのimportは禁止。
4. **容量・実行の別判定**：保存目標3,800,000,000,000バイト、空き安全余白200,000,000,000バイト（実HDD空き未計測）。上流repo合計と**選択ファイル＋依存＋staging**の容量を混同しない。推論RAMは3–4 bit量子化前提でOS/KV/エンコーダ等を含み512,000,000,000バイト未満が条件。backend、ABI、zero-point、KV精度、context長、batch、デバイスを記録してから個別検証する。
5. **承認**：全132件`priority.download_approved=false`。本体の取得・実行・再配布を一切行わず、`queues/approved.json`は変更しない。新調査帯はダウンロード順序ではない。

## 6. 事前登録する仮説と検証計画（H/T/D/C/U）

- **H（反証可能仮説）**：2026-11-03〜2027-11-03に、新たなモデル・データ公開制約がまずT1の対象限定資産に現れ、その後T2の高能力一般、最後にT3の公開ウェイト・参照データへ順序的に拡大する。測度は**原配布者の公開状態・ライセンス・アクセス条件の新規変更イベントの日時**。これは事前検証対象であり、発生確率・施行日を宣言しない。
- **T（最小検証）**：132件を固定対象として同じ週に一度、公式repo状態、Gated/非公開の差分、ライセンス正文、配布者告知、政府官報を記録。最低12週の試験（n_min=132資産/週、計12回の定点観測を計画、2026-11-03起点）。変更前後の時刻、一次URL、適用法域、権利理由、同一revisionの再取得可否を保存する。調査はメタデータのみ、モデル・datasetは取得しない。観測の自動化は未設定。
- **D（判定条件）**：`PASS`は独立した少なくとも2配布者でT1制限強化を観測し、その後独立した2配布者のT2とT3に対応する制約が順序通りに確認された場合。`FAIL`はT1先行なしに独立した2配布者のT3の制約強化が先行するか、広範同時施行で順序仮説が成立しないと確認された場合。`UNCERTAIN`は変更が少ない、期間不足、同一配布者のみ、証拠/理由不十分な場合。**現在はUNCERTAIN**。12週間では判定不能なら2027-11-03まで観測拡張を提案するが自動開始しない。
- **C（対立仮説・破れ方）**：顔/声・権利/個人情報などの分野別契約変更がS1に集中するだけ、または旧S3のデータ削除が先行、提供者の事業撤退/コスト低下/規制緩和が主因、全面同時変更、公開維持など。公開停止の因果を無根拠に「悪用能力規制」と帰属しない。
- **U（不確かさ）**：変更理由の非公開、適用管轄の差、利用者認証の未確認、配布状態の時間的不整合、週次観測による最大約7日の変化時刻打切り、モデル版差・出典バイアス。発生率・分散を測定していないため合成標準不確かさ`u_c`は算定不能、包含係数`k`は非適用、確率や信頼区間は設定しない。

## 9. 法制・ML依存・長期保存の交点と監査方法

- **国際法・政策**: [EU AI Act第53条](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-53)・[第55条](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-55)はGPAIに対する義務を規定するが、全公開ウェイトの一律取得禁止を意味しない。[米GAO B-337935（2026-05-12）](https://www.gao.gov/products/b-337935)はAI Diffusion Ruleの不執行と正式廃止を区別する。対象法域、当事者、配布行為、具体的な適用時点に関する確認は引き続き必要。
- **配布変化の実例**: [GEITje作者の削除告知（2025-01-25）](https://goingdutch.ai/en/posts/geitje-takedown/)、[Stability AIのCommunity License更新（2024-07-05）](https://stability.ai/news-updates/license-update)、[LAIONの安全審査と改訂版の再公開（2024-08-30）](https://laion.ai/blog/relaion-5b/)は、理由・適用対象・可逆性が互いに異なる。これらから個別モデルの消失確率を算出しない。
- **技術的再現性**: Base、派生、学習データ、Encoder、VAE、codec、tokenizer、MoE全expertを独立に構成管理し、選択checkpoint・依存閉包・型・版・ハッシュ・ライセンスを組み合わせて監査する。[Model Cards](https://doi.org/10.1145/3287560.3287596) と [Datasheets for Datasets](https://doi.org/10.1145/3458723) は情報項目の一次研究であって権利許諾そのものではない。
- **技術アーカイブ**: 配布URL・配布者・確認日・固定revision・ファイルSHA-256・法的保存条件の同時固定が必要。Software Heritage等のソースコードアーカイブや匿名ミラーは、機械学習モデルの同一checkpointと利用権限を自動的には保証しない。全モデルのファイル取得・権限回避・未検証コード実行は本提案の対象外。
