## 2. 〈応用・転用例〉— 実運用での改善点

**デジタルアーカイブ：** 135件の主重み/データ原本を固定revisionまで追跡できるが、未確認762ファイルを実物保存済みと数えない。バックアップ復元には**実HDDでのSHA検証**が別に必要。

**機械学習・MLOps：** 60,043件の公開元ファイル参照があっても、完全な学習済み依存・runtime ABIは揃わない。推論コードの閉包、CUDA/CPU、driver、wheel、KVキャッシュ、量子化zero-pointは個別検証する。

**法務・ソフトウェア供給網：** Gated17資産を「未確認SHAだから一般公開からハッシュを取得すればよい」と扱わない。本人の合意・再配布可能性・LICENSE/NOTICE原文を確認し、同一SHAでも権利承継は自動でない。
