## 2. 実際に共通重みと確認できた箇所

**Wan-Animate-2とLongCat Avatar 1.5は別の動画生成・制御学習済みモデル**だが、いずれもLongCat-Video/Wan配布元の映像VAEファイルに共通のSHA-256を持つ。

| 検査項目 | 固定ソースでの確認値 |
|---|---|
| リポジトリ | Wan-AI/Wan2.2-Animate-2-14B-Diffusers と meituan-longcat/LongCat-Video |
| ファイル相対パス | vae/diffusion_pytorch_model.safetensors |
| 公開SHA-256 | d6e524b3fffede1787a74e81b30976dce5400c4439ba64222168e607ed19e793 |
| ファイル容量 | **507,591,892 byte** |
| 保存判断 | 両モデルの特殊な重みを保持する場合でも、共有VAEは1つの内容として計上可能 |

これは**配布元が公表したSHAとbyteの一致**であり、ユーザー実機のファイルハッシュを再計算したものではない。両モデルの利用権限・ローダー互換性を別途確認する。片方のモデルを削除してよいという判断ではない。

過去R19のChatR LoRA重みについても、R21で固定した同じLoRA本体とSHA-256・byteが一致していた。**過去研究の証拠を新しい取得資産に数えない**。ただしLoRAとQwen-Image原本は別の学習済みファイルであり、それぞれ必要なら保管する。

## 3. 未確認のファイルと、形式の違いは勝手に消さない

15パッケージ181参照のうち**93参照は公表SHA-256の記録がない**。README、LICENSE、設定、Tokenizerなどの小ファイルも含む。これらは『重複している』とも『重複していない』とも立証できない。リビジョン・相対パス・byteを台帳に保持し、追加のSHA検査までは共有可能容量を推定しない。

R39に残したMistral Native、GPT-OSS original/・Metal、FLUX2のGated構成は同じ学習済みモデルの別表現か専用backendの再現に価値がある場合があり、**15パッケージの主シナリオから外れただけでHOLD/REJECTではない**。StubeliusのBeta1/Beta2も、単なる量子化ではなく異なるマージ段階なので、研究対象から削除しない。

## 4. 読み取り専用の再計算

新しいPython標準ライブラリの監査コマンドを追加した。R40のすべての選択ファイルについて、元マニフェスト内のrepo ID・40文字コミット・パス・byte・公開SHAが変わっていないか再検証し、**SHAが一致するものだけを一度に計上**する。機械学習モデルを実行・ダウンロード・削除したり、取得承認を追加する機能はない。

```bash
python3 scripts/audit_candidate_manifest_union.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

**PASSの意味**：公開元の静的証拠の整合性のみ。物理容量・権利・実行性能のPASSではない。

## 5. H/T/D/C/U と変数表

| 記号 | 意味 | 単位（SI） | 定義・定義域・型 |
|---|---|---|---|
| B_sum | 選択候補の参照サイズ合計 | byte | 392,782,078,397。非負整数スカラー。実機保存済み量ではない |
| B_dup | 配布元SHAが一致する重複サイズ | byte | 507,591,892。非負整数スカラー、元ハッシュの一致のみ |
| B_unique | 共有SHA分を1回だけ計上した容量 | byte | 392,274,486,505。非負整数スカラー、未検証は残す |
| N_unknown | SHA-256未記録の参照数 | 1 | 93。無次元の整数スカラー |
| C | 長期保全計画上限 | byte | 4,000,000,000,000。ユーザー申告の非負整数 |
| F | 実機最低空き領域 | byte | 200,000,000,000。独立に守る非負整数 |

**次元チェック**：B_sum、B_dup、B_unique、C、Fはいずれもbyte、N_unknownは無次元。**H**：モデルの異なる学習成果を残しつつ同一内容ファイルだけ共有可能。**T**：元11マニフェストをPythonで読み取り、ファイルIDとSHA・byteを照合。**D**：静的メタデータの全項目一致でPASS、パス・byte・SHA不整合でFAIL、物理配置・権利・品質はUNCERTAIN。**C**：公開SHAが偽または内容更新、同名異ファイル、異なるローダーで共通VAEが利用できない可能性。**U**：実機空き、元ファイル真正性、権利、依存関係の不確かさが残り、合成u_cと包含係数kは測定なしで未算定。
