# v8 深掘り調査：150B以上のモデルを取得しない（2026-11-03、履歴）

**現行の総数監査は[v9](parameter-audit-v9-2026-11-03.md)。** ここにある「82通過・25未確認」はv8時点の履歴であり、現在は95通過・12未確認。上限150Bは変わらない。

## 決定と前提

- **モデルの総パラメータ数が150,000,000,000以上なら、ウェイト・量子化版・追加依存を含めて保存対象外（EXCLUDED）**。等号は除外。量子化・SSDオフロード・8GB VRAMで動作した事例・MoEの活性パラメータ数が小さいことは除外を覆さない。
- 150B未満は**パラメータゲートだけ通過**し、規制連鎖予測S1→S2→S3、容量3.8TB、空き200GB、推論ピークRAM512GB未満、利用許可、固定ファイルマニフェストを別々に検査する。
- 正確な総数が分からないモデルは**取得対象として確定できない**が、調査候補として保持し、配布元一次情報を確認する。推測値だけで通過させない。
- **MoEなら全expert、埋め込みテーブル、MTP等の付属学習済み重みを合算**し、主モデルの一部パラメータだけを150B判定に流用しない。複数独立モデルから構成されるパイプラインは、単独モデルの総数と別依存を明示する。
- データセットはモデルの総パラメータ閾値の対象外だが、容量・権利・同意制約を維持。

## ルールの優先順位

1. **硬い除外条件：総モデルパラメータ150B以上**（無条件に重みを取得しない）。
2. **規制の連鎖予測**：S1悪用リスクの先行制限→S2高性能汎用/科学→S3公開ウェイト全般、というユーザー指定のストレスケースを維持。
3. **独自性・コスパ**：同系の量子化/派生を重複保存せず、正確な選択容量、原本価値、RAM/VRAM/SSDオフロード実用性、速度と品質を確認。
4. **独立の権利・実行・承認ゲート**：Gated許諾・LICENSE・本人同意・安全なバックエンド・最終固定lockのハッシュ承認。パラメータ数合格はダウンロード許可ではない。

## H / T / D / C / U

- **H**：今後作る最終`*.lock.json`が参照するモデルは、MoE非活性expertと追加の学習済み埋め込みを含む**総数が150B未満**。合否対象は109モデルのゲートと、承認キュー内の該当モデル数。
- **T**：各モデルの第一配布元モデルカード/構成・Hubパラメータ値を照合し、n=109の全件の現行statusを読み取り専用で再計算。未知25件を無理にPASSにせず、一次資料を取得できるまで停止。境界値149,999,999,999・150,000,000,000・180B・1.05T・unknownをコード上のテストケースとする。
- **D**：PASS＝150B未満の確認＋別の権利/RAM/容量承認条件をすべて満たす。FAIL＝150B以上または誤ってEXCLUDEDを取得対象に入れる。UNCERTAIN＝総数未確認。**モデル109件のパラメータゲートのみ82 PASS／2 FAIL／25 UNCERTAIN**。
- **C**：125B主モデルと51B n-gram/MTPを別名義で分割して合計を過小評価、MoEの活性数だけ採用、量子化後ファイルサイズを総パラメータ数と勘違い。
- **U**：Hubの欠落値、概数、学習済み補助部品の境界、共有パラメータや新revisionでの変更が主な不確かさ。閾値近傍で数え方が曖昧な場合はUNCERTAINとする。合成標準不確かさ`u_c`と係数`k`は実測データ不足のため未算出。
