# v7：総パラメータ250B以上のハード除外を復活（2026-11-03）

## 決定（前回方針の訂正）

ユーザーの元来の条件は**総パラメータ250B以上のモデルを除外**すること。以前の「総パラメータでは一律除外しない」はこの条件を無断で変更した誤りであり、**v7で撤回**した。

- **モデルの総パラメータ数が250,000,000,000以上**：**除外**（トークン当たりの活性数が少ないMoE、FP8/3～4bitなどの量子化、SSDオフロードでも例外なし）。
- **総パラメータ数が250,000,000,000未満**：パラメータ条件を通過。ただし3.8TBの保存予算、200GB空きの実測、安全なアクセス/本人同意、実測前提のRAM上限512GB未満、速度・再取得リスクは別に審査。
- **総パラメータ数が未確認**：除外と断定しないが、**本人承認用の最終lock manifest作成を停止**する。メーカー原文・モデル構成を参照し、MoEの**全expertを含めた総数**を確定する。
- **データセット23件には250Bモデルパラメータ制約を直接適用しない**。容量、データ権利、プライバシーは別途審査する。
- **量子化・変換版は元モデルの総パラメータ数を引き継ぐ**。全重みのビット数や、実行時にRAM/SSDへオフロードする方法で250Bの制限を抜けるという扱いは禁止する。

## H / T / D / C / U

- **H（反証可能な動作要件）**：全ての最終lockは、対象モデルの総パラメータが250B未満と確認された場合に限って審査を通す。達成指標はモデル109件のゲートカバレッジと、誤って250B以上が候補キューへ入る件数（許容0）。
- **T（最小検証）**：109件のHubメタデータ一括照会、数値未記載26件のうちMistral Large 4の公式資料で確認済み。残る25件は各公式モデルカード/config等で総数を確認後に再審査する。次の追試は未実施。
- **D（合否条件）**：PASS＝250B未満かつ権利・容量・RAM・固定ファイル・個別承認を別途満たす。FAIL＝250B以上（総数、MoE含む）。UNCERTAIN＝総数が未確認。現在、109件のうち83 PASS(パラメータゲートのみ)、1 FAIL、25 UNCERTAIN。
- **C（破れ方）**：モデル名のBを総数と誤読する、MoEの活性数だけで判定する、量子化重み容量を総数の代わりに使う、構成要素の数え方を誤る。
- **U（不確かさ）**：Hubメタデータの欠落、モデルカードの丸め、重み共有・埋め込み・専門エンコーダの計上範囲、モデル系列の変更。証拠が欠ける場合は法令/性能を推測せずUNCERTAIN。未確定モデルの合成不確かさ`u_c`、係数`k`は数値化できない。
