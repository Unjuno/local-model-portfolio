# 小型モデルの異常な専門性能を保存する検証基準（R26）

1. **人間超えは自称や別分野のスコアで判定しない**：同じ実務タスクで熟練者・人間ベースラインが必要で、AIMEやWebArenaの点数だけから「人間より強い」と推定しない。AIの総合能力への一般化も禁止。
2. **小型の定義を厳格に**：モデル名0.9Bでも本当の公開テンソル総数が1.078Bならその値を採用。MoEは活性数でなく非活性expertまで。draft+target、checker+generatorは必要構成一式の総数も記録。BF16ファイルサイズとQ4推論VRAMを混同しない。
3. **性能の差分・負の証拠**：小型モデルが9Bなどを超える場合、同条件のベンチ名・サンプル・ハーネス・temperature/think、変更時刻と評定者を保持。高いWebArenaと低いGPQAを同時報告。author-onlyベンチでSELECTへ格上げしない。
4. **供給網**：HFの公開LFS SHA256と重みbyteは証拠。正本コミットがmainなら厳密な固定版ではない。モデルを取得しないまま計算したローカルSHAの確認済み印を付けない。LICENSE/NOTICEと補助コードの真正性も別。
5. **規制の実証**：[商務部・科技部公告2026年第48号](https://www.mofcom.gov.cn/zwgk/zcfb/art/2026/art_0a31a3c9ac404f7a9b0e917ce3412997.html)はAI技術の輸出管理改訂**案**と指定技術輸出の暫定登録であり、既に公知・オープンソース公開済みの技術は管理対象から除く方針。人間超えモデルの一律禁止でも全HF重みの撤去でもない。2026-04-30 CAC公式発表は危険なopen-sourceモデルとデータセットの清理・審査不十分を問題視した。2026-09-14安全治理框架3.0はリスク分類の枠組み。**単なる『人間超えで即禁止』とする包括的な法令の発見には至らず**、モデル固有削除確率や中国共産党の意図を推測・数値化しない。
6. **本人の目的**：個人非商用研究・長期保存。metadata license unknown単体で除外しないが、公開ウェイト・実機保存・再配布/P2P seed・提供サービスを区別する。現在の段階でfinal lock、ダウンロード、無審査のプログラム実行をしない。

関連分野：機械学習と統計（性能非劣性、標本と汚染）、コンピューターシステム工学（量子化/投機復号/メモリ）、安全政策とデジタル保存（公開制限、配布条件、供給網の固定版）。
